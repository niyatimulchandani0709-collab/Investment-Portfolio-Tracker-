📊 Investment Portfolio Analytics Dashboard

An Excel-based Investment Portfolio Analytics Dashboard designed to track investments, analyze portfolio performance, and present key financial insights through interactive Excel tools.

📌 Project Overview

This project demonstrates practical Advanced Excel and financial analysis skills by combining portfolio tracking, data analysis, Pivot Tables, and interactive Slicers into a structured investment analysis solution.

🚀 Key Features

- 📈 Investment Portfolio Tracker — Organize and monitor investment data.
- 📊 Analysis Dashboard — Present key portfolio metrics and performance insights.
- 📋 Pivot Table Analysis — Summarize and analyze investment data efficiently.
- 🎛️ Interactive Slicer — Filter portfolio data dynamically for focused analysis.

🛠️ Tools & Skills

- Microsoft Excel
- Advanced Excel
- Pivot Tables
- Slicers
- Financial Data Analysis
- Portfolio Performance Analysis
- Data Organization & Visualization
